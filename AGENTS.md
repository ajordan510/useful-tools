# Project workflow

- After completing updates in this repository, run the checks appropriate to the changes, commit the task's changes, and push them to the remote `main` branch. The user has authorized this as the default workflow; do not ask for confirmation again unless a later instruction changes the scope or authorization.
- Include only changes belonging to the current task. Preserve unrelated local changes and untracked files.
- Preserve remote history: fetch before pushing, integrate any newer remote changes, and do not force-push `main`.
- If checks or the push fail, resolve the issue where possible and report any remaining blocker accurately.
