01 / establish the scale

Start with acoustic power and a core length

  • Power: use per-engine thrust F, exhaust velocity U, engine count N and efficiency η. The approximation is W = (η/100) N F U / 2; η is entered in percent.
  • Read the figure: increasing exit Mach number lengthens the aerodynamic core reference. Its length sets where DSM-II places acoustic power along the plume.
  • In this tool: Lc,free = C Deff(1 + 0.38 M)². C = 3.45 is the Eldred default; C = 1.75 is the Varnier / Haynes–Kenny sensitivity option.
  • Keep the inputs consistent: merged clusters use Deff = D√N; independent, co-located engines use D. Neither resolves individual nozzle spacing.
Example: with D = 1 m and M = 3.4, the free core is 18.12 m with Eldred or 9.19 m with Varnier. With F = 1 MN, U = 2800 m/s, N = 1 and η = 0.5%, acoustic power is 7.00 MW.

SP-8072 Eq. 1 corresponds to 1% efficiency; 0.5% is the nominal starting choice used here. A shorter core is a modeling choice, not a universal accuracy improvement.

02 / distribute acoustic power

Divide the plume into radiating slices

  • Read the axes: horizontal position is distance along the plume divided by core length. The vertical axis is a logarithmic power density per unit normalized length, not the power of a single slice.
  • In this tool: integrate the digitized historical curve from 0.1 to 5 core lengths. The receiver calculation uses the requested slices (240 by default); the field map uses 60.
  • Convert before summing: each slice receives power proportional to 10G(q)/10 Δq, with q = s/Lc. Power normalization makes all slice weights sum to one.
  • Location matters: moving this distribution changes source-to-receiver distances, angles and the frequencies assigned to the sources.

Historical limitation: Gee (2021) traced a plotting error into this Figure 12 distribution. This tool retains the curve for a transparent heritage DSM-II calculation. Normalization repairs its energy balance, not its physical provenance. Read the finding.

03 / assign frequencies to each slice

Each source radiates a full spectrum

  • Read the figure: the horizontal variable is the modified axial Strouhal number. The symbols show the experimental scatter around the empirical spectral shape.
  • Map to frequency: this tool uses Stx = f s / (M c₀), where s is distance along the plume and c₀ is ambient sound speed. The paper's x is that along-flow distance, not necessarily the map's horizontal coordinate after a bend.
  • Integrate band power: the curve is a spectral density. Integrate across the actual third-octave edges, then multiply by the slice power; do not treat a point on the curve as a band level.
  • Normalize the full spectrum: power outside the selected bands stays outside. The displayed bands are never rescaled to contain all acoustic power.
Example: at s = 20 m, M = 3.4 and c₀ = 343 m/s, Stx = 1 corresponds to f ≈ 58.3 Hz. Moving sources upstream raises the frequency associated with the same dimensionless spectral feature.
04 / account for the assumed flow path

A bend and core termination do different things

  1. Place the deflector: enter nozzle-to-deflector distance d. A value of zero means no deflector.
  2. Turn the centerline: β rotates the outgoing plume from +x toward +y. β = 90° sends it along +y. This is the plume turn angle, not a plate inclination.
  3. Choose core behavior: without termination, Lc remains the free core length. With termination, Lc = min(Lc,free, d); the source distribution and spectral scale then move accordingly.
  4. Inspect the geometry graphic: it reports d, β, the free/effective core lengths and the modeled source extent along the path.

The published illustration is drawn vertically. Our coordinates rotate the initial exhaust to +x. The tool uses a sharp, piecewise-straight centerline; it does not calculate a curved deflector surface, impingement noise, shielding or water suppression.

05 / propagate to a receiver

Distance and viewing angle both matter

  • For each slice: calculate distance r to the receiver and angle θ from the slice's local downstream flow tangent. After a bend, that tangent follows the outgoing plume.
  • Read the curves: directivity varies with both θ and ordinary Strouhal number f Deff/U. The loudest direction is not the same at every frequency.
  • Apply spreading: subtract 10 log₁₀(4πr²) from source band power level, then add directivity, the selected propagation-loss term and one reflection correction.
  • Respect the domain: the heritage interpolation holds outside Sr = 0.004–0.4 and θ = 20–180°, with a warning. SATURN directivity supports only θ = 0–90°.

Using far-field directivity for individual near-field slices is an empirical approximation acknowledged by the original report. The separate directivity chart lets you inspect the implemented curve for each band.

06 / sum energy and check the evidence

Separate prediction, numerical checks and measured evidence

  1. Within each band: add the uncorrelated slice contributions in linear mean-square pressure, then convert to dB.
  2. Across bands: repeat that energy sum for OASPL. Apply band-center A-weighting for dBA. The user allowance is added separately to the design level.
  3. Read the published comparison: the Saturn V data show why core termination can matter in a specific launch geometry. They do not establish a universal correction for every engine.
  4. Check this implementation: numerical checks verify its equations and energy accounting. An exact measured replication still needs complete engine, geometry and measurement inputs.

Which research options should I compare?

  • Core relation: compare Eldred and Varnier rather than assuming the shorter core is always better. James et al. (2016) found full-scale overall-level support for the original relationship in their solid-motor comparisons.
  • Core termination: compare preserved and terminated cores when a deflector is present; distinguish this from simply changing the flow direction.
  • Modern stationary model: Mathews' SATURN components use a measured-spectrum fit, s/D = 9.85 Sr⁻⁰·²¹ and a released Atlas V directivity dataset. This is a separate source model, not a correction to Figure 12.
  • Propagation: the optional SATURN empirical loss uses the released code's parameters. It is not a weather-specific, nonlinear or terrain propagation model.
